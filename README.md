# Uddin Auto Insurance Website

A static multi-page marketing website for Uddin Insurance, offering auto, home, and commercial insurance coverage across Maryland, DC, and Virginia.

## Project structure

- `index.html` — homepage
- `about.html` — company story and values
- `team.html` — team member profiles
- `auto-insurance.html` — auto insurance services
- `home-insurance.html` — home insurance services
- `commercial-insurance.html` — commercial insurance services
- `contact.html` — contact form and office details
- `quote.html` — quote request form
- `css/styles.css` — site styling
- `js/main.js` — simple menu toggle and demo form behavior

## How to use

1. Open the site in a browser by double-clicking any `.html` file.
2. Keep the `css/` and `js/` folders in the same directory as the HTML files.
3. Edit page content directly in the HTML files.

## Notes

- The navigation menu is responsive and includes a mobile toggle.
- The forms currently use demo behavior in `js/main.js`; integrate a backend or form service to capture submissions.
- All pages already reference `css/styles.css` and `js/main.js`.
